# 코코포리아 로그 변환기

코코포리아(ココフォリア)에서 내보낸 로그를 보기 좋은 HTML 한 장으로 바꿔주는 도구입니다.
설치 없이 `index.html`을 브라우저로 열기만 하면 됩니다. 로그는 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

## 사용법

1. 코코포리아 룸 메뉴 → **로그 출력**으로 로그 파일(.html)을 받습니다.
2. `index.html`을 열고 파일을 끌어다 놓습니다.
3. 레이아웃·배경·탭·캐릭터를 원하는 대로 고른 뒤 **HTML 다운로드**를 누릅니다.

`sample/sample-log.html`로 바로 시험해볼 수 있습니다.

## 기능

- **레이아웃 3종**: 채팅(말풍선) / 대본 / 깔끔한 한 줄
- **배경 3종**: 밝게 / 어둡게 / 종이
- **탭 필터**: 잡담(other) 탭 등을 체크 해제해 뺄 수 있음
- **캐릭터 설정**: 표시 여부, 색 변경, 이름 변경(같은 이름으로 바꾸면 한 사람으로 합쳐짐)
- **다이스 강조**: BCDice 결과(`＞`로 이어진 판정)를 카드로 표시하고 성공/실패/크리티컬/펌블에 색을 입힘
- **연속 발언 묶기**
- 텍스트 로그(`[main]이름：본문`)와 Shift_JIS 인코딩 로그도 읽을 수 있음
- 결과물은 외부 파일 없이 혼자 열리는 HTML 한 장 (모바일 대응)

## GitHub Pages로 배포하기

저장소 Settings → Pages에서 브랜치를 선택하면 `https://<아이디>.github.io/nabicoco/`에서 바로 쓸 수 있습니다.
