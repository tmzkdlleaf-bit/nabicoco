# 코코포리아 로그 변환기

코코포리아(ココフォリア)에서 내보낸 로그를 보기 좋은 HTML로 바꿔주는 도구입니다.
설치 없이 `index.html`을 브라우저로 열기만 하면 됩니다. 로그는 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

## 사용법

1. 코코포리아 룸 메뉴 → **로그 출력**으로 로그 파일(.html)을 받아 `index.html`에 끌어다 놓습니다.
   (로그 파일 없이 룸 링크만 넣어도 됩니다.)
2. 룸 링크를 넣고 **불러오기** → 스탠딩·표정(과 채팅 기록)을 가져옵니다.
3. 스타일·탭·캐릭터를 고르고, 미리보기에서 대사를 클릭해 수정합니다.
4. **HTML 다운로드** 또는 **티스토리용 코드 복사**.

`sample/sample-log.html` 또는 화면의 **예시 로그로 체험해보기**로 바로 시험해볼 수 있습니다.

## 룸 링크로 스탠딩 · 표정 불러오기

룸 링크(`https://ccfolia.com/rooms/...`)를 넣고 **불러오기**를 누르면 룸의 캐릭터 스탠딩과 표정을 가져옵니다.

- **채팅 기록도 가져오기**를 켜면 채팅에 기록된 "그 대사를 보낼 때 쓴 표정"까지 가져옵니다.
  - 로그 파일을 먼저 넣었다면 → 대사마다 실제로 쓴 표정이 연결됩니다.
  - 로그 파일이 없다면 → 룸 채팅으로 로그를 만듭니다.
- 코코포리아 웹앱에 공개적으로 들어 있는 설정값으로 **익명 로그인**해서 읽습니다. 개인 계정 정보는 쓰지 않으며,
  익명 로그인 정보는 브라우저에 저장해 다시 씁니다.
- **코코포리아 공식 기능이 아닙니다.** 코코포리아 사정에 따라 언제든 막힐 수 있고, 비공개 룸은 읽을 수 없습니다.

### 링크로 안 될 때

- **방법 A · 북마크**: 노란 **스탠딩 가져오기** 버튼을 북마크바로 끌어다 놓고, 코코포리아 룸 화면에서 클릭 →
  뜨는 창의 내용을 변환기에 붙여넣고 **적용**. (본인 로그인으로 읽습니다)
- **방법 B · 캐릭터 복사**: 코코포리아에서 캐릭터 말을 우클릭 → 복사 → 변환기에 붙여넣고 **적용**.
- 캐릭터 목록에서 이미지 주소를 직접 넣을 수도 있습니다.

캐릭터 이름이 같으면 자동으로 연결되고, 다르면 캐릭터 목록에서 직접 고를 수 있습니다.

**표정 연결 순서**: 직접 고른 표정 → 대사 속 `@표정이름` 태그 → 룸 채팅에 기록된 표정 → 직전 표정(옵션) → 기본 이미지.
미리보기에서 대사를 클릭하면 표정을 직접 고를 수 있습니다.

## 기능

- **레이아웃**: 채팅(말풍선) / 대본 / 깔끔한 한 줄
- **다크 · 라이트 양방향**
  - 변환기 화면: 시스템 / 라이트 / 다크 선택 (기억됨)
  - 결과물: 보는 사람 기기 설정을 따라가는 **자동** 또는 밝게/어둡게 시작. 밝은 배경(흰색·종이·민트)과
    어두운 배경(먹색·밤하늘·검정)을 따로 고름. 내려받은 HTML에는 전환 버튼(◐)이 들어감
  - 티스토리용 코드도 `light-dark()`로 보는 사람 설정을 따라감 (옛 브라우저는 밝은 쪽으로 표시)
  - 이름 색이 배경에 묻히지 않도록 WCAG AA(4.5:1) 기준으로 자동 보정
- **아이콘**: 원 / 네모 / 스탠딩(세로), 크기 32~200px (기본 72px)
- **가독성**: Pretendard 글꼴, 본문 16px · 줄간격 1.75, 한국어 단어 단위 줄바꿈
- **작업 보존**: 이 브라우저에 자동 저장 → 다시 열면 "이어서 하기", 작업 파일(.json)로 백업/불러오기
- **편의**: 삭제·되돌리기 알림, `Ctrl+S` HTML 다운로드, 수정 창 `Ctrl+Enter` 저장, 모바일 하단 탭(설정/미리보기)
- **나레이션**: 캐릭터(또는 대사 하나)를 나레이션으로 지정하면 아이콘·이름 없이 본문처럼 표시 (본문/가운데/상자)
- **꾸밈 문법**: `**굵게**` `*기울임*` `__밑줄__` `~~취소선~~` `{#e53935|색 글씨}` `{big|크게}` `{small|작게}`, 괄호 속 문장 흐리게
- **대사 수정**: 미리보기에서 대사를 클릭 → 내용·화자·종류·표정 변경, 꾸밈 버튼, 삭제/되살리기
- **탭 필터**, **캐릭터 표시/색/이름 변경**(같은 이름으로 바꾸면 합쳐짐), **다이스 결과 강조**, **연속 발언 묶기**
- **티스토리 백업**: `<style>` 없이 모든 꾸밈을 인라인으로 넣은 코드를 복사 → 티스토리 글쓰기의 HTML 모드에 붙여넣기
- 텍스트 로그(`[main]이름：본문`)와 Shift_JIS 로그도 읽을 수 있음

## GitHub Pages로 배포하기

저장소 Settings → Pages에서 브랜치를 선택하면 `https://<아이디>.github.io/nabicoco/`에서 바로 쓸 수 있습니다.
