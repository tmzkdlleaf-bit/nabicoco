# 코코포리아 로그 변환기

코코포리아(ココフォリア)에서 내보낸 로그를 보기 좋은 HTML로 바꿔주는 도구입니다.
설치 없이 `index.html`을 브라우저로 열기만 하면 됩니다. 로그는 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

## 사용법

설정 패널은 다섯 탭으로 나뉘어 있습니다.

1. **📂 불러오기**: 코코포리아 룸 메뉴 → **로그 출력**으로 받은 로그 파일(.html)을 끌어다 놓거나, 룸 링크를 넣고 **룸에서 불러오기**.
   불러오면 **불러온 결과**(대사·탭·인물 수, 이미지, 시각 정보, 표정 연결)가 나와서 제대로 읽혔는지 바로 확인할 수 있습니다.
2. **🎨 꾸미기**: 레이아웃·다크/라이트·아이콘·글꼴·잡담·비주얼 노벨 설정.
3. **👥 인물·탭**: 캐릭터 색·이미지·나레이션, 탭 형식(메인/잡담/정보/비밀).
4. **🎬 장면**: 배경·삽화·BGM·섹션 넣기. 미리보기에서 대사 사이의 **＋**로도 그 자리에 바로 넣을 수 있습니다.
5. **💾 저장**: HTML · 티스토리 · 비주얼 노벨 · 섹션별 ZIP · 작업 파일. 자주 쓰는 셋은 패널 아래에 늘 떠 있습니다.

미리보기에서 대사를 누르면 수정 창이 열리고, 위쪽 **📜 로그 / 🎬 비주얼 노벨**로 두 모양을 바꿔 볼 수 있습니다.
여러 대사를 한꺼번에 고칠 때는 미리보기 위의 **🛠 일괄 편집**을 씁니다.

`sample/sample-log.html` 또는 화면의 **예시 로그로 체험해보기**로 바로 시험해볼 수 있습니다.

## 룸 링크로 스탠딩 · 표정 불러오기

룸 링크(`https://ccfolia.com/rooms/...`)를 넣고 **불러오기**를 누르면 룸의 캐릭터 스탠딩과 표정을 가져옵니다.

- **채팅 기록도 가져오기**를 켜면 채팅에 기록된 "그 대사를 보낼 때 쓴 표정"까지 가져옵니다.
  - 로그 파일을 먼저 넣었다면 → 대사마다 실제로 쓴 표정이 연결됩니다.
  - 로그 파일이 없다면 → 룸 채팅으로 로그를 만듭니다.
- 코코포리아 웹앱에 공개적으로 들어 있는 설정값으로 **익명 로그인**해서 읽습니다. 개인 계정 정보는 쓰지 않으며,
  익명 로그인 정보는 브라우저에 저장해 다시 씁니다.
- **코코포리아 공식 기능이 아닙니다.** 코코포리아 사정에 따라 언제든 막힐 수 있고, 비공개 룸은 읽을 수 없습니다.

### 링크로 안 될 때

- **방법 A · 북마크**: 노란 **스탠딩 가져오기** 버튼을 북마크바로 끌어다 놓고, 코코포리아 룸 화면에서 클릭 →
  뜨는 창의 내용을 변환기에 붙여넣고 **적용**. (본인 로그인으로 읽습니다)
- **방법 B · 캐릭터 복사**: 코코포리아에서 캐릭터 말을 우클릭 → 복사 → 변환기에 붙여넣고 **적용**.
- 캐릭터 목록에서 이미지 주소를 직접 넣을 수도 있습니다.

캐릭터 이름이 같으면 자동으로 연결되고, 다르면 캐릭터 목록에서 직접 고를 수 있습니다.

**표정 연결 순서**: 직접 고른 표정 → 대사 속 `@표정이름` 태그 → 룸 채팅에 기록된 표정 → 직전 표정(옵션) → 기본 이미지.
미리보기에서 대사를 클릭하면 표정을 직접 고를 수 있습니다.

## 기능

- **레이아웃**: 채팅(말풍선) / 대본 / 깔끔한 한 줄
- **다크 · 라이트 양방향**
  - 변환기 화면: 시스템 / 라이트 / 다크 선택 (기억됨)
  - 결과물: 보는 사람 기기 설정을 따라가는 **자동** 또는 밝게/어둡게 시작. 밝은 배경(흰색·종이·민트)과
    어두운 배경(먹색·밤하늘·검정)을 따로 고름. 내려받은 HTML에는 전환 버튼(◐)이 들어감
  - 티스토리용 코드도 `light-dark()`로 보는 사람 설정을 따라감 (옛 브라우저는 밝은 쪽으로 표시)
  - 이름 색이 배경에 묻히지 않도록 WCAG AA(4.5:1) 기준으로 자동 보정
- **아이콘**: 원 / 네모 / 스탠딩(세로), 크기 32~200px (기본 72px)
- **가독성**: Pretendard 글꼴, 본문 16px · 줄간격 1.75, 한국어 단어 단위 줄바꿈
- **작업 보존**: 이 브라우저(IndexedDB)에 자동 저장 → 다시 열면 "이어서 하기", 작업 파일(.json)로 백업/불러오기.
  이미지를 넣은 긴 로그도 저장되고, 탭을 닫을 때 기다리던 저장을 바로 합니다
- **편의**: 삭제·되돌리기 알림, `Ctrl+S` HTML 다운로드, 수정 창 `Ctrl+Enter` 저장, 모바일 하단 탭(설정/미리보기)
- **나레이션**: 캐릭터(또는 대사 하나)를 나레이션으로 지정하면 아이콘·이름 없이 본문처럼 표시 (본문/가운데/상자)
- **꾸밈 문법**: `**굵게**` `*기울임*` `__밑줄__` `~~취소선~~` `{#e53935|색 글씨}` `{big|크게}` `{small|작게}`, 괄호 속 문장 흐리게
- **대사 수정**: 미리보기에서 대사를 클릭 → 내용·화자·종류·표정 변경, 꾸밈 버튼, 삭제/되살리기
- **탭 설정**: 탭마다 형식(메인 / 잡담 / 정보=상자 / 비밀=점선 상자), 상자 색, 글자색(이름에도), 굵게, 기울임.
  같은 정보·비밀 탭이 이어지면 한 상자로 묶기, 형식별 탭 이름표, 잡담 회색, 색 섞기, Alt+클릭으로 그 탭만 보기
- **캐릭터**: 표시/색/이름 변경(같은 이름이면 합쳐짐), 캐릭터별 여러 이미지(표정·의상)와 대표 이미지,
  캐릭터별 나레이션 모양, 정렬(등장순/많이 말한 순/가나다순), Alt+클릭으로 그 캐릭터만 보기
- **캐릭터 설정 보관함**: 색·이미지·나레이션 설정을 저장해 두고 다음 세션 로그에 이름이 같은 캐릭터에게 한 번에 적용
- **대사 편집**: 내용·화자·탭·종류·표정 변경, 아래에 대사 추가, 위/아래 이동, 번호(#N), 삭제/되살리기
- **🛠 일괄 편집**: 대사 번호 범위(#3~#40)·탭·화자로 대상을 고르고
  - 찾아 바꾸기 (정규식 가능, 몇 곳이 바뀌는지 미리 표시)
  - 한꺼번에 삭제·되살리기·원래대로, 탭 옮기기, 화자 바꾸기, 대사/나레이션 바꾸기
  - 대사 수정 창의 **여기부터 일괄…**로 그 대사부터 범위 지정. 모두 `Ctrl+Z`로 되돌릴 수 있음
- **배경 · 삽화 · BGM · 섹션**: 장면 탭의 큰 버튼이나 미리보기의 **＋**로 넣기.
  - 이미지는 주소·파일 선택·**붙여넣기(Ctrl+V)**·끌어다 놓기, 넣기 전에 미리보기
  - BGM은 유튜브 링크만 넣으면 썸네일과 **제목이 자동으로** 채워지고, 시작 시간은 `1:30`처럼 입력 (`t=90` 링크도 인식)
  - 위치를 "몇 번째 대사 뒤"로 바로 지정, 장면 흐름 목록에서 위/아래로 옮기기
  - 섹션 나누기(제목·목차) → 섹션별 내보내기와 **섹션별 ZIP**
- **잡담**: 잡담 형식 탭은 올라온 **시각 기준으로 가까운 것끼리(기본 5분) 묶어서** 접어 둠 (눌러서 펼침).
  시각이 없는 로그는 바로 붙은 잡담끼리 묶음. 시각은 시각이 함께 저장된 로그나 룸 채팅 기록에서 가져옴
- **되돌리기 / 다시 실행**: `Ctrl+Z` / `Ctrl+Y` (머리글 ↶ ↷ 버튼)
- **미리보기 검색**: 검색어 강조, Enter로 다음 결과 (긴 로그는 다른 쪽에 있는 결과까지 찾아감)
- **긴 로그**: 미리보기는 300묶음씩 쪽으로 나눠 그려서(◀ 앞쪽 / 뒤쪽 ▶) 수천 줄 로그도 설정을 바꿀 때 느려지지 않음.
  내려받는 HTML에는 전부 들어감
- **세부 디자인**: 글꼴 7종, 줄 간격, 글자 간격, 대사 사이 간격, 양옆 여백, 본문 폭, 배경색 직접 지정, 대사 구분선,
  빈 아이콘 비우기, 스탠딩 테두리·배경 없애기, 나레이션 문장마다 줄 나누기
- **🎬 비주얼 노벨 백업**: 로그를 비주얼 노벨처럼 넘겨 보는 HTML 한 장으로 내보내기
  - 배경 · 스탠딩(1~4명 / 대화창 옆 얼굴 / 없음) · 이름표가 붙은 대화창 · 글자가 한 자씩 나오는 효과
  - **대화창 디자인**: 반투명 / 종이 / 게임풍 / 미니멀 / 밝은 창
  - **연출**: 대사 수정 창에서 대사마다 화면 흔들림 · 번쩍임 · 암전 · 말하는 인물 깡총 · 이 대사 뒤 퇴장.
    스탠딩은 나올 때와 내려갈 때 부드럽게 나타나고 사라짐
  - **같은 인물은 무대에서 내려갈 때까지 같은 자리**. 자리가 차면 가장 오래 말 안 한 사람과 교체, 챕터가 바뀌면 무대 비움
  - 스탠딩은 **대화창 위**(안 가림) 또는 대화창 뒤(겹침), 크기 조절 — 보는 사람도 플레이어 설정에서 바꿀 수 있음
  - 잡담은 **화면 옆 채팅창**에 시각과 함께 쌓임 (💬 버튼·C 키로 열고 닫기, 모바일은 접힌 채 새 글 개수 표시)
  - 배경은 배경으로, 삽화는 CG로. BGM은 그 장면부터 자동 재생, 섹션은 챕터 제목 화면
  - 클릭·Space·Enter 다음, ← 이전, 자동 진행(A), 빨리 넘기기(S), 지난 대사 로그(L), 챕터 선택, 이어서 보기, 전체 화면(F)
  - 보는 사람이 글자 속도·자동 대기·BGM을 조절할 수 있음. 변환기 미리보기의 🎬로 바로 확인
- **내려받는 HTML**: 탭·캐릭터 **필터바**(떠 있는 버튼 / 위에 고정), 다크/라이트 전환 버튼, 섹션 목차
- **설정 기억하기**: 모양 설정을 다음 로그에도 그대로
- **티스토리 백업**: `<style>` 없이 모든 꾸밈을 인라인으로 넣은 코드를 복사 → 티스토리 글쓰기의 HTML 모드에 붙여넣기
- **불러오기**: 코코포리아 HTML 로그(예전 형식 · 아이콘이 들어 있는 새 형식), **탭별로 나뉜 로그 ZIP**,
  텍스트 로그(`[main]이름：본문`), Shift_JIS 로그, ccfolia log getter JSON, 다른 로그를 새 섹션으로 **이어붙이기**
  - ZIP은 `[すべて]`(전체) 파일이 있으면 그것을 쓰고, 없으면 탭별 파일을 시각 순서로 합침
  - 새 형식 로그에 든 아이콘은 대사마다 "보낼 때 쓴 아이콘"으로 연결되고, 인물별 표정 목록에도 들어감.
    내려받는 HTML에는 같은 아이콘을 한 번만 넣음. 티스토리 코드는 용량 때문에 첫 글자 아이콘으로 바꿈(이미지 주소를 넣으면 그대로 나옴).
    비주얼 노벨에서는 작은 아이콘이라 스탠딩 대신 대화창 옆 얼굴로 보여 줌 (룸 링크로 스탠딩을 불러오면 큰 그림으로)
- **다이스 결과 강조**, **연속 발언 묶기**

### 만들지 않은 것

- Imgur 업로드 · 이미지 프록시: 별도 서버가 필요해서 한 파일로 동작하는 이 도구에는 넣지 않았습니다.
  삽화는 이미지 주소를 넣거나 내 컴퓨터 파일을 HTML 안에 넣는 방식으로 대신합니다.

## GitHub Pages로 배포하기

1. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다 (처음 한 번).
2. 기본 브랜치에 올릴 때마다 테스트가 통과하면 `https://<아이디>.github.io/nabicoco/`에 자동으로 올라갑니다.
   (Actions 탭의 **테스트 · 배포**에서 진행 상황을 볼 수 있습니다)

## 테스트

브라우저(Chromium)로 화면을 직접 눌러 보는 테스트가 `tests/`에 있습니다. 코코포리아·유튜브 등 바깥 주소는 가짜 응답으로 막아 두고 돌립니다.

```sh
npm install
npx playwright install chromium   # 처음 한 번
npm test
```

### 직접 확인해 주세요

테스트는 가짜 응답으로 돌기 때문에 아래는 실제 환경에서 한 번 확인이 필요합니다.

- 실제 코코포리아 **로그 출력** 파일 → 불러오기 탭의 **불러온 결과**에서 대사·탭·인물 수가 맞는지
- 실제 **룸 링크** → 스탠딩·표정이 불러와지는지 (코코포리아 쪽 사정으로 막힐 수 있음)
- **티스토리** 글쓰기 HTML 모드에 붙여넣은 뒤 다크/라이트에서 보기 좋은지
- 내려받은 **비주얼 노벨** HTML을 휴대폰에서 열어 보기
