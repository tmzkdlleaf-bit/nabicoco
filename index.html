코코포리아 로그 변환기

코코포리아에서 내보낸 로그(.html / .txt)를 보기 좋은 HTML로 바꿔줍니다. 파일은 서버로 전송되지 않고 브라우저 안에서만 처리돼요.

1. 로그 파일

여기에 파일을 끌어다 놓거나 클릭
코코포리아 → 룸 메뉴 → 로그 출력

2. 스타일

레이아웃
배경
글자 크기
제목

3. 탭

체크를 해제한 탭의 메시지는 결과에서 빠집니다. (잡담 탭 제외 등)

4. 캐릭터

이름을 바꾸면 결과에도 반영돼요. 두 캐릭터에 같은 이름을 넣으면 한 사람으로 합쳐집니다.

5. 저장

미리보기
왼쪽에서 로그 파일을 불러오면 여기에 미리보기가 나타납니다.
