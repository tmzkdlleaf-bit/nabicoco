코코포리아 로그 변환기

코코포리아에서 내보낸 로그를 보기 좋은 HTML로 바꿔줍니다. 로그는 서버로 전송되지 않고 브라우저 안에서만 처리돼요.

1. 로그 파일

여기에 파일을 끌어다 놓거나 클릭
코코포리아 → 룸 메뉴 → 로그 출력

2. 스탠딩 · 표정 불러오기

룸 링크
  1. 아래 노란 버튼을 북마크바로 끌어다 놓기 (처음 한 번만)
  2. 룸 열기 → 룸 화면에서 그 북마크 클릭
  3. 뜨는 창의 내용을 복사해서 아래 칸에 붙여넣기
스탠딩 가져오기

코코포리아는 로그인한 사람만 룸 정보를 읽을 수 있어서, 링크만으로는 이미지를 가져올 수 없어요. 그래서 룸 안에서 북마크를 실행하는 방식이에요.
대사 안에 @표정이름이 있으면 그 표정이 자동으로 연결돼요.

4. 탭

체크를 해제한 탭의 메시지는 결과에서 빠집니다. (잡담 탭 제외 등)

5. 캐릭터

이름을 바꾸면 결과에도 반영돼요. 두 캐릭터에 같은 이름을 넣으면 한 사람으로 합쳐집니다. 나레이션에 체크한 화자는 아이콘과 이름 없이 본문처럼 표시돼요.

6. 저장

티스토리 백업

  1. 티스토리 글쓰기 → 오른쪽 위 기본모드를 HTML로 바꾸기
  2. 복사한 코드를 붙여넣고 저장

티스토리용 코드는 <style> 없이 모든 꾸밈을 태그 안에 직접 넣어서, 블로그 스킨이 바뀌어도 모양이 유지돼요.
